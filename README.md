## Installation

Follow these simple steps to install and activate the WMS Theme:

1. Open the **Command Palette** in Visual Studio Code (press `Ctrl+Shift+P` on Windows/Linux or `Cmd+Shift+P` on macOS).
2. Type `Install Extension` and select the "Extensions: Install Extension" option.
3. In the search bar, type `wms-theme` and press `Enter`.
4. Select **WMS Theme** from the list of results to install.
5. After installation, click "Set Color Theme" or go to `Code > Preferences > Color Theme` (or `File > Preferences > Color Theme` on some systems) and select **WMS Theme** from the list.
